# Tinkers' Construct 1.21.1 移植版

本项目是 **Tinkers' Construct 3** 面向 **Minecraft 1.21.1 + NeoForge** 的社区移植版，基于上游 `3.12.0` 版本开展适配工作。

项目重点是完成代码迁移、依赖适配、版本兼容性修复与构建维护，不对原模组内容作重新介绍或扩展。

## 项目信息

- Minecraft：`1.21.1`
- Mod Loader：`NeoForge`
- 移植版本：`3.12.0-port`
- 必需依赖：`Mantle 1.12.0-port`
- 状态：开发与适配中，部分内容可能尚未完成

## 构建

环境要求：JDK 21。

```bash
gradlew build
```
